- `ToolConfig.request` is required. In-process Arena tools keep a request stub and run through the `tools/index.ts` dispatcher.

- Admin helpers are `adminBadRequestResponse`, `adminConflictResponse`, `adminInternalErrorResponse`, and `adminNotFoundResponse`.
- Zod errors are read from `.issues`.
- `BlockConfig` is no longer generic.
- `downloadFileFromStorage` / `downloadServableFileFromStorage` take a fourth options argument. `prepareToolExecution` is four arguments. `SecureFetchOptions.profile` is required.
