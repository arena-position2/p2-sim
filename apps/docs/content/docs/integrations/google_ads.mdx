Use [Google Ads](https://ads.google.com) in Sim to list accessible accounts and campaigns, retrieve ad groups and performance metrics, and run custom Google Ads Query Language (GAQL) queries. These read operations support campaign reporting and budget monitoring workflows.

Connect your Google account and select a reporting operation. Google requires the `adwords` OAuth scope even for read-only reports; Sim's Google Ads operations do not create or modify ads, budgets, or billing.

Google Ads API access belongs to the Google Cloud project that owns the OAuth client. Self-hosted deployments must enable the Google Ads API and configure the project's access level in the [Google Ads API overview](https://console.cloud.google.com/google/ads-apis/overview). Test access works only with Google Ads test accounts; production accounts require an appropriate production access level. [Developer tokens were retired on September 9, 2026](https://developers.google.com/google-ads/api/docs/api-policy/developer-token) and are no longer needed.

Use the client account's Customer ID for reports. If your Google user accesses that account through a manager, set Manager Customer ID in the additional fields. List Customers returns accounts directly accessible to the signed-in user, which may include the manager rather than its client accounts. Test accounts do not serve ads and cannot demonstrate real impressions, clicks, or spend.
All report operations return one page at a time (up to 10,000 rows). Use the returned `nextPageToken` in Page Token with unchanged query inputs to retrieve the next page. `totalCount` counts the current page. Custom Query also returns `totalResultsCount`, which ignores GAQL LIMIT. Daily performance reports return one row per entity and date; sum counts before computing ratios. Costs are in micros of the customer account currency.

## Use the block [#usage-instructions]

Simplified Google Ads block that uses AI (Grok with GPT-4o fallback) to automatically generate GAQL queries from natural language prompts. Perfect for quick queries without complex configuration. Supports campaign performance, keyword analysis, search terms, and more.

## Actions

### Google Ads V1 Query

Simplified Google Ads query tool that generates GAQL queries using AI (Grok with GPT-5 fallback). Just provide a natural language prompt and let AI handle the rest.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `accounts` | string | No | Google Ads account key \(admin workspaces only\) |
| `prompt` | string | Yes | Natural language prompt describing what data you want \(e.g., "show campaign performance last 30 days"\) |
| `oauthCredential` | string | No | Google Ads OAuth credential \(non-admin workspaces\) |
| `accountId` | string | No | Google Ads account ID \(non-admin workspaces\) |
| `customerId` | string | No | Google Ads customer ID \(non-admin workspaces\) |
| `developerToken` | string | No | Google Ads API developer token \(non-admin workspaces\) |
| `managerCustomerId` | string | No | Manager account customer ID \(non-admin workspaces, optional\) |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Whether the query succeeded |
| `query` | string | Original natural language query |
| `gaql_query` | string | Generated GAQL query |
| `query_type` | string | Type of query \(campaigns, keywords, etc.\) |
| `tables_used` | json | List of tables used in the query |
| `metrics_used` | json | List of metrics used in the query |
| `results` | json | Query results with campaigns and totals |
| `account` | json | Account information \(id, name\) |
| `execution_time_ms` | number | Query execution time in milliseconds |
