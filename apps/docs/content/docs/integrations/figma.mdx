## Use the block [#usage-instructions]

Integrate Figma into your workflow. Create new Figma files, convert designs to HTML/React/Angular code, manage comments, and access team projects. Requires Figma API key for authentication.

## Actions

### Generate Figma Design with AI

Generate AI-powered Figma designs automatically using Claude AI and browser automation

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `description` | string | No | Optional description for the file |
| `designPrompt` | string | Yes | AI prompt to generate design content |
| `projectId` | string | Yes | Figma project ID to create the file in |
| `brandGuidelines` | file | No | Optional brand guidelines file \(PDF, image, or text\) to inform the design |
| `wireframes` | file | No | Optional wireframes file to guide the design structure |
| `additionalData` | file | No | Optional additional data or reference files |
| `additionalInfo` | string | No | Additional text information to guide the design generation |
| `designTargets` | array | No | Device/layout experiences \(desktop, mobile, etc.\) to generate simultaneously |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | Success message with Figma file URL |
| `metadata` | object | File metadata including key, name, and generated content |
|   ↳ `key` | string | Figma file URL |
|   ↳ `name` | string | File name |
|   ↳ `lastModified` | string | Last modified timestamp |
|   ↳ `thumbnailUrl` | string | Thumbnail URL |
|   ↳ `version` | string | File version |
|   ↳ `role` | string | User role in the file |
|   ↳ `editorType` | string | Editor type |
|   ↳ `linkAccess` | string | Link access level |
|   ↳ `designPrompt` | string | Design prompt used |
|   ↳ `projectId` | string | Project ID |
|   ↳ `figmaFileUrl` | string | URL to the created Figma file |
|   ↳ `renderedData` | string | Generated HTML/CSS code |
| `cost` | object | LLM cost for design generation \(overall tool price\) |

</ReferenceDetails>

### Convert Figma to HTML with AI

Convert Figma designs to HTML and CSS using advanced AI processing. Extracts data from Figma API using file key and node ID, then generates responsive code with design system extraction.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `fileKey` | string | Yes | Figma file key \(required\) |
| `nodeId` | string | No | Specific node ID to convert \(optional - converts entire file if not provided\) |
| `includeStyles` | boolean | No | Whether to include CSS styles \(default: true\) |
| `responsive` | boolean | No | Whether to make the output responsive \(default: true\) |
| `outputFormat` | string | No | Output format \(html, react, or vue\) |
| `customPrompt` | string | No | Custom AI prompt for specific requirements |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `metadata` | object | Metadata about the conversion process including combined HTML/CSS |
|   ↳ `fileKey` | string | Figma file key |
|   ↳ `nodeId` | string | Figma node ID |
|   ↳ `processingTime` | number | Processing time in milliseconds |
|   ↳ `aiModel` | string | AI model used for conversion |
|   ↳ `tokensUsed` | number | Number of tokens used |
|   ↳ `combinedHtml` | string | Generated HTML document with embedded CSS styles |
| `cost` | object | LLM cost for the conversion \(overall tool price\) |

</ReferenceDetails>
