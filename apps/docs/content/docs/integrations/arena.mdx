### Arena Create Task

Create a milestone task in Arena using workspace selectors (client, project, group, assignee).

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `task-name` | string | Yes | Name of the task |
| `task-description` | string | Yes | Detailed description of the task |
| `task-client` | string | No | Client associated with the task |
| `task-project` | string | No | Project under which the task belongs |
| `task-group` | object | No | Task group |
| `task-assignee` | string | No | Assignee |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Indicates if transform was successful |
| `output` | json | Output from Arena |

</ReferenceDetails>

### Arena Search Task

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `search-task-client` | string | No | Client associated with the task |
| `search-task-project` | string | No | Project under which the task belongs |
| `search-task-assignee` | string | No | User ID of the assignee |
| `search-task-visibility` | string | No | Task visibility \(Internal / Client Facing\) |
| `search-task-state` | string | No | State of the task |
| `search-task-due-date` | string | No | Due date of the task |
| `search-task-max-results` | string | No | Max number of search results \(page size\) |

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `ts` | string | Timestamp when response was transformed |
| `response` | object | Response from Arena |
| `success` | boolean | Indicates if transform was successful |
| `output` | object | Output from Arena |

</ReferenceDetails>

### Arena Add Comment

Add a comment to an Arena task using client, project, group, and task selectors. Set those on the block; you supply the comment text and optional client note.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `comment-client` | object | Yes | Client \(set in the block; not an LLM argument\) |
| `comment-project` | string | Yes | Project \(set in the block; not an LLM argument\) |
| `comment-group` | object | Yes | Task group \(set in the block; not an LLM argument\) |
| `comment-task` | string | Yes | Target task \(set in the block; not an LLM argument\) |
| `comment-text` | string | Yes | Comment body to post. |
| `comment-client-note` | boolean | No | Client-facing note \(optional\). Default false if unsure. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Indicates if transform was successful |
| `output` | object | Output from Arena |

</ReferenceDetails>

### Arena Get Token

Get Arena token for the logged-in user or workflow owner. Both must have @position2.com email.

<ReferenceDetails>

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Whether the request succeeded |
| `found` | boolean | Whether a token was found for the user |
| `userId` | string | User id \(when found\) |
| `name` | string | User display name from user table \(when found\) |
| `email` | string | User email \(when found\) |
| `arenaToken` | string | Arena token for the user \(when found\) |
| `timezone` | string | User timezone from Arena details \(when found\) |
| `persona` | string | User persona from Arena details \(when found\) |
| `reason` | string | Error or failure reason \(when not found\) |

</ReferenceDetails>
